Давай напишем telegram чат-бота (лучше на python),  который будет:
- брать переменную `BOT_TOKEN` из файла `.env`
- разбирать страницы сайта `https://chlhl.ru`
- находить дивизионы команд
- находить команды в этих дивизионах
- находить будущие игры команды:
	- день
	- время
	- место проведения (стадион)
	- адрес стадиона
	- соперника
- находить прошедшие игры команды:
	- счёт
	- соперника
- сохранять информацию в базу данных (желательно SQLite):
	- таблица с дивизионами
	- таблица с командами
	- таблица с результатами игр (сохраняем день, время, счёт, соперника, стадион, адрес)
	- таблица с предстоящими играми (сохраняем день, время, счёт, соперника, стадион, адрес)
- бот должет показывать пользователю информацию по:
	- предстоящим играм (по дивизионам, по командам)
	- по прошедшим играм (по дивизионам, по командам)
	- давать возможность пользователю подписаться на обновления по командам или по дивизионам
	- подписаться можно на один или несколько дивизионов
	- подписаться можно на одну или несколько команд
	- пользователю надо предоставлять возможность выбирать дивизион, то есть он может не знать название дивизионов и пользователю надо подсказывать название дивизиона
	- пользователю надо предоставлять возможность выбирать команду, то есть он может не знать название конманды и пользователю надо подсказывать название команды 
- обновлять информацию:
	- сразу при старте
	- в 08:00
	- в 13:00
	- в 18:00
	- в 23:00 
	- в 23:55 
- логирование аккаунтов, которые:
	- информацию о пользователе (всю , которую достали)
	- подписки/отписки на дивизион/команду/команды
	- время подписки/отписки
	- время первого подключения
