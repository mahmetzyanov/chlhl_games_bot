# Telegram-бот ЧЛХЛ (chlhl.ru)

Бот показывает расписание и результаты игр Челябинской любительской хоккейной
лиги, позволяет подписываться на дивизионы и команды и присылает уведомления
о новых играх и результатах.

## Возможности

- 📅 **Предстоящие игры** — по дивизионам и по командам (день, время, тур,
  стадион, адрес стадиона, соперник).
- 🏁 **Прошедшие игры** — результаты по дивизионам и по командам (счёт,
  соперник, дата, стадион).
- 🔔 **Подписки** — на один или несколько дивизионов, на одну или несколько
  команд. Названия дивизионов и команд подсказываются кнопками, знать их
  заранее не нужно. Отписаться можно из списка «Мои подписки» одним нажатием.
- 🗄 Данные хранятся в SQLite (`chlhl.db`).
- 📊 **Логирование пользователей:** каждое сообщение, команда и нажатие кнопки
  записываются в таблицу `user_events` и в файл `users.log`; при первом общении
  с ботом сохраняются открытые данные аккаунта (id, @username, имя, язык,
  премиум-статус, bio — если Telegram его отдаёт) в таблицу `users`. Подписки
  и отписки логируются с указанием дивизиона/команды.
- 🔄 Обновление данных: сразу при старте и по расписанию — 08:00, 13:00,
  18:00, 23:00 и 23:55 (в локальном времени машины, на которой запущен бот).
- 📣 После каждого обновления подписчики получают уведомления о новых
  результатах и новых/изменённых играх.

## Быстрый старт

```bash
pip install -r requirements.txt

# создайте .env рядом с bot.py на основе .env.example:
#   BOT_TOKEN=1234567890:ваш-токен
python bot.py
```

Токен бота создаётся у [@BotFather](https://t.me/BotFather) (`/newbot`).

## Структура проекта

| Файл | Назначение |
|---|---|
| `bot.py` | Telegram-бот, меню, подписки, рассылка, планировщик |
| `parser.py` | Парсер сайта chlhl.ru (дивизионы, команды, календарь, стадионы) |
| `db.py` | Схема и запросы SQLite |
| `config.py` | Токен, путь к БД, время обновлений |
| `requirements.txt` | Зависимости |
| `.env.example` | Шаблон файла с токеном |

## Схема базы данных

- `divisions` — дивизионы (`tournament_id`, `name`);
- `teams` — команды (`team_id`, `division_id`, `name`, `city`);
- `stadiums` — стадионы и адреса (`name`, `address`);
- `games_past` — сыгранные игры: дата, время, тур, команды, счёт, стадион, адрес;
- `games_upcoming` — предстоящие игры: дата, время, тур, команды, стадион, адрес;
- `subscriptions` — подписки пользователей (`kind`: `division`/`team`);
- `users` — открытые данные пользователей: id, @username, имя/фамилия,
  язык, премиум-статус, bio, первый и последний визит;
- `user_events` — журнал действий: время, пользователь, действие, детали.

Аналогичный журнал пишется в файл `users.log` рядом с ботом. Посмотреть
аккаунты из БД можно так:

```bash
sqlite3 chlhl.db "SELECT * FROM users ORDER BY last_seen DESC"
sqlite3 chlhl.db "SELECT * FROM user_events WHERE user_id=42 ORDER BY id DESC LIMIT 50"
```

Когда матч на сайте получает счёт, он автоматически переносится из
`games_upcoming` в `games_past`, а подписчики получают уведомление.

## Замечания

- Расписание обновлений задаётся в `config.py` (`UPDATE_TIMES`) и использует
  локальное время сервера. Если сервер живёт не в вашей таймзоне, запустите
  бота с переменной окружения `TZ=Asia/Yekaterinburg`.
- Разметка сайта может измениться — тогда при следующем обновлении парсер
  запишет предупреждение в лог и бот продолжит работать с имеющейся базой.
- Кнопка «♻️ Обновить данные» в меню запускает обновление вручную в любой момент.

## Приватность

Бот хранит только ту информацию, которую Telegram сам передаёт при общении
(id, @username, имя, язык, премиум-флаг) и публичное bio профиля. Пароли,
номера телефонов и прочие закрытые данные не запрашиваются и не сохраняются.
